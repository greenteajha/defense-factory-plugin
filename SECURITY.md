# Security policy

Please do not post an exploitable weakness, credentials, private code, or reproduction details in a public issue or pull request. Use GitHub's private vulnerability reporting for this repository when available, or contact the maintainer privately through a channel listed on the GitHub profile. Include affected version, impact, and a minimal reproduction. The maintainer will acknowledge and coordinate disclosure before publishing details.

This plugin is guidance for authorized defensive work. It does not grant repository access, create an isolated environment, or enforce host permissions. Treat outputs as review material, especially before changing code or closing a finding.
